Full Commercial Architecture · Revision 1.0

显性调用。精品加载。广告买单。

用户安装 SkillFlux npm 包后，显性调用一个元 Skill。本地 Runtime 去云端搜索经过质检的最佳 Skill，安全加载进当前项目与当前上下文，再由认证输出层在最终回答末尾追加一句透明广告。不注册，不登录，不订阅。

03 · End-to-end Sequence

一次显性调用，二十个可审计步骤。

广告决策在 Skill 执行时并行预取，等模型结束后由 Output Controller 追加，不延迟、不改写、不干预原回答。

01
npm安装与 init

写入本地 MCP 配置、Bootstrap Skill、项目策略和可重置匿名 ID。

02
Host能力握手

确认动态上下文、项目写入、审批 UI 与 final-response hook 能力。

03
User显性调用

用户以 $skillflux 或宿主 mention 提出原任务。

04
Local安全摘要

本地只抽取任务分类、语言、框架、宿主能力和权限上限。

05
Search匿名检索

向公共 Search API 发送粗粒度特征，不发送源码、secrets 或完整 prompt。

06
Index仅检索已批准集

先按安全状态、宿主兼容、Runtime 版本、权限上限和 license 过滤。

07
Resolver求解 Skill 图

解析精确版本、依赖、冲突、adapter 以及多 Skill 组合顺序。

08
Ranker质量排名与解释

任务匹配、评测成绩、成功率、兼容性和新鲜度决定候选。

09
Local生成密封计划

绑定项目根、候选图、每个 digest、权限、评测证据与过期时间。

10
Policy本地批准

无写入或已信任权限可自动通过；扩权、安装和更新由本地 UI 确认。

11
CDN内容寻址下载

Runtime 只下载计划中的不可变 URL，并支持断点、重试与本地共享缓存。

12
Trust供应链验证

校验根元数据、发布签名、透明日志、文件哈希、SBOM 与撤回新鲜度。

13
Sandbox安全解包与扫描

限制大小、文件数与压缩比，拒绝路径穿越、链接、设备文件和未声明代码。

14
Project原子安装

先写隔离目录，通过后一次性切换，更新 lockfile 和可回滚快照。

15
MCP即时上下文注入

工具结果返回当前轮必需的 Skill 指令与资源，无需重启宿主。

16
Adapter持久激活

将同一已验证版本映射到宿主 Skill 目录，供后续轮次与离线复用。

17
Agent执行原任务

模型按选中 Skill 完成工作；广告文案不在模型上下文中。

18
Ad并行广告决策

基于粗粒度任务分类、地区、频控与安全规则预取已审核的一句文案。

19
Output确定性追加

认证 Host Adapter 捕获最终回复，在流式结束后追加显著标注“广告”的句子与签名点击链接。

20
Events匿名记录与回滚

上报签名展示、点击、隐藏与 Skill 结果；失败可一键回滚并保留本地审计。

DUAL LOAD

“加载到当前项目”必须同时实现当前轮注入和项目持久化。只写磁盘会导致当前轮无法使用，只注入上下文则无法复现。

05 · npm Runtime + MCP Contract

npm 包是本地控制面，不是一个网页 SDK。

npx skillflux init 完成宿主探测、MCP 注册、Bootstrap Skill 安装、匿名 ID 与本地策略初始化。之后所有项目写入都只由该进程完成。

01host_handshakeread

返回宿主、Runtime、项目与最终输出 hook 的能力协商结果。

02search_skillsread

搜索已批准 Skill，返回证据、兼容性、权限和可组合候选。

03resolve_install_planread

生成绑定项目、精确版本图、digest、权限与 QA 证据的密封计划。

04install_skill_graphwrite

下载、验签、安全解包、原子安装并写入 lockfile 与回滚点。

05activate_skill_contextread

把主指令和必需资源注入当前轮，并返回已持久安装位置。

06read_skill_resourceread

按 manifest 允许列表延迟读取参考、模板和静态资源，不暴露任意路径。

07inspect_installationread

列出精确图、provenance、QA 证据、撤回新鲜度、本地改动与可回滚点。

08rollback_or_removedelete

回滚到上一已验证快照或完整移除，并原子更新宿主映射与 lockfile。

PATH A / IMMEDIATE

当前轮立即生效

MCP 工具结果返回主入口指令、已展开依赖顺序与可读资源 URI，宿主不需重启。

PATH B / PERSISTENT

当前项目可复现

包存入内容寻址缓存，项目锁文件记录精确图与证据，Host Adapter 建立宿主可发现的映射。

PLAN ID ≠ APPROVAL

plan_id 只防止计划被替换。项目写入的批准来自本地 Host UI、CLI 或用户明确配置的本地自动策略。

OUTPUT IS NOT AN MCP TOOL

广告追加不依赖模型再调一次工具，而是宿主完成事件触发的本地 Output Controller。

Package + Evidence Contract

包、权限、质检证据一起签名。

每个 Skill 是内容寻址的不可变发布单元。自然搜索不相信发布者自述，而是验证与 digest 绑定的评测、人审和安全证据。

  • ✓精确文件哈希与依赖图
  • ✓声明式权限与宿主 adapter
  • ✓SBOM、静态扫描与红队评测
  • ✓人审结果、签名时间与透明记录
  • ✓撤回、废弃、替代版本与紧急 kill switch

06 · Quality Supply Chain

“精品”必须是一条生产线，不是一个标签。

收录的每个版本都经历八道独立关卡，上线后继续复评。任意一道失败都会移出可搜索集，而不是只下调排名。

Q01 / INTAKE

来源与许可

确认发布来源、license、所有权、依赖和原始提交摘要。

Q02 / NORMALIZE

规范化

统一 manifest、文件清单、权限、输入输出、adapter 和任务分类。

Q03 / SCAN

静态安全

检查提示注入、数据外泄、路径操纵、危险脚本、密钥和依赖漏洞。

Q04 / SANDBOX

沙箱行为

在伪造项目、诱饵 secrets、断网和最小权限环境中观察真实行为。

Q05 / EVAL

黄金任务评测

使用分类任务集评分完成度、稳定性、可复现性、成本和回归。

Q06 / RED TEAM

对抗测试

针对恶意项目文件、冲突指令、不可信网页与越权工具进行对抗。

Q07 / HUMAN

人工评审

阅读指令、权限理由、评测差异、依赖和上游更改，给出签名决定。

Q08 / RELEASE

签名与持续复评

写入透明日志、发布不可变包，监测上游、反馈、宿主更新与安全情报。

draft→quarantine→automated pass→human review→approved→deprecated→revoked
REVOCATION CONTRACT

撤回会在分钟级传播到搜索、CDN 授权、Runtime 新安装策略与已安装状态；高危撤回可触发全局禁用和强制回滚建议。

HARD

COMMERCIAL REALITY

公共 Registry 和可修改的 npm 客户端意味着用户可以绕过官方 Output Controller，技术上无法强制“每次 Skill 使用都产生广告收入”。可售卖的库存必须来自官方认证输出通道；点击/转化优先于不可完全信任的客户端曝光计费。

open distribution ≠ forced monetization
NATURAL LANGUAGE OUTPUT

普通文本回答在末尾追加一句“广告｜…”，并保证去掉广告后的正文 digest 与模型原输出一致。

MACHINE-READABLE OUTPUT

JSON、diff、表格协议、代码块、文件与终端退出码不得被广告污染；广告放在宿主 UI 的 sibling sponsored block，仍由认证 renderer 确认展示。
