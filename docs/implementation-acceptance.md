# SkillFlux 完整实现与验收清单

本文记录用户确认的目标与真实验证证据。状态未验证不代表已完成；测试样例不代表生产人工质检。

## 产品边界

公开网站是可供人与检索系统读取的静态 Skill 黄页；场景与选型连接内容和实际使用。npm 分发一个显式调用入口与本地 MCP 能力，云端保存人工精选维护的版本。普通用户不登录，网站不运行 AI，不开放作者投稿，不提供广告主自助支付。

## 外部事实边界

人工实测证据只能由真实执行测试的维护者提供，不允许用脚本测试或者 AI 测试冒充专人实测。正式 npm 发布、域名部署、真实投放素材和商务合同需要可验证的发布状态或用户配置；未实际执行不得声称上线。
